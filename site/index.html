Core Pipeline

From Idea to Publication

Five automated stages, orchestrated as a nested DAG. Every stage is resumable from checkpoints and observable in real time via WebSocket.

🏗
01

Architecture Design

Validates the requirement, decomposes the project into modules → files → leaf functions, generates a full dependency DAG, and performs static cycle detection. Human review gate with feedback loop.

validation module_split file_split dag_validate arch_gate
⚙️
02

Parallel Code Generation

Generates function stubs, then spawns parallel LLM tasks for each function body. Assembles via AST, writes to disk, runs sandbox validation with auto-repair loops.

arch_scaffold map:fn_codegen ast_assemble sandbox_fix_loop
🌲
03

MCTS Beam Search Optimization

Critic LLM proposes optimization angles; Engineer LLMs generate patches. Each patch is AST-checked and sandbox-evaluated. Human gate allows rollback, manual frontier selection, or early stopping.

mcts_critic map:engineer ast_check beam_select mcts_gate
🧬
04

U2E Evolutionary Optimization

Population-based evolutionary search per function: mutation, crossover, short-term reflection. Long-term structured memory accumulates across iterations. Diversity-aware elite selection prevents early convergence.

mutation crossover short_reflect diversity_select
📄
05

Automated Paper Writing

Retrieves literature via Semantic Scholar, builds a ChromaDB vector store with full-text embeddings, writes all 4 sections in parallel, then merges into a final LaTeX manuscript with BibTeX citations.

literature_retrieval chroma_vector_db 4×parallel_write latex_merge

Architecture

Built on a declarative
agent orchestration engine.

Every step is declared in JSON. The runtime resolves dependencies, parallelizes independent nodes, and streams real-time events over WebSocket.

🔗

DAG Compute Graphs

Computation is declared as JSON DAGs. Nodes without dependencies execute in parallel automatically via asyncio.gather().

graphs/*.json
⚡

Human Gate Mechanism

Architecture review and MCTS decisions block on asyncio.Queue channels. Approve, give feedback, roll back — from the web UI.

channel & gate
📡

Real-time WebSocket

Every step emits step_start, step_done, gate_waiting events. React UI renders live progress and diffs.

WebSocket
🔁

Checkpoint & Resume

Each run writes step outputs to disk. Pass resume_checkpoint_dir to restart from the exact point of failure — no re-running expensive LLM calls.

fault-tolerant
🏖

Isolated Code Sandbox

All generated code runs in a sandboxed subprocess with configurable timeout. stdout, stderr, exit code, and metric values are streamed back for evaluation.

sandbox.py

Optimization Stage 1

MCTS
Beam Search.

A tree search over code transformations. Each generation, a Critic identifies promising optimization angles; Engineers generate patches in parallel.

Critic → Engineer Pipeline

Critic proposes (op, angle) pairs. Multiple Engineer LLMs generate patches in parallel. AST validity checked before sandbox evaluation.

Human-in-the-Loop Gate

After each generation you can continue, manually select the frontier, roll back, or stop and write back the best node.

Auto-Rollback on Stagnation

If N consecutive generations show no improvement the search automatically rolls back to the last best node.

Optimization Stage 2

U2E Evolutionary
Optimization.

After MCTS finds a strong candidate, U2E's evolutionary algorithm searches a far larger solution space through mutation, crossover, and structured memory — per function, in parallel.

🧬 Mutation

Generates diverse variations of elite individuals using LLMs with temperature variation.

🔀 Crossover

Combines two parent implementations guided by short-term reflection on their differences.

🧠 Long-term Memory

Structured insights accumulate across all iterations and inform future mutation prompts.

🌍 Diversity Select

Penalizes individuals too similar to the elite archive, keeping the population exploring.
